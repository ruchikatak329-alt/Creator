# Mansi Sankhla - Content Creator Portfolio

## Put it on Vercel (new project)
1. Create a NEW GitHub repo and upload everything in this folder (index.html, cut.png, sticker1.png, sticker2.png, api/, package.json, vercel.json).
2. On vercel.com: Add New > Project > import that repo > Deploy.
3. Settings > Environment Variables > add ADMIN_PASSWORD = the password you want. Then Deployments > Redeploy.
4. Optional, only for uploading video files from your device: Storage > Create > Blob > connect it to the project. Photos do not need this, and you can paste a YouTube or .mp4 link for videos instead.

## Editing
- Open yoursite.vercel.app/admin and enter the password (or use the small "Admin" link in the footer).
- Edit Site: click text to type, click a photo or video frame to upload from your device.
- Style selected: click any text, box or sticker, then change its colour, fill, font and size. Replace image swaps a picture. Delete removes stickers, cards and pills.
- + Image adds any picture you can drag around. Stickers adds emoji. Design changes the fonts and main colours for the whole site.
- Download Updated Site, then replace index.html in your repo with that file and let Vercel redeploy. Only then do your edits show for everyone.

## Images
cut.png (your photo in the About poster), sticker1.png (kitten) and sticker2.png (hamster) must stay in the same folder as index.html.
